# 語音實測 · Voice Test (P3d)

> 故事模式 24 句對白，比較兩種配音來源：目前用的瀏覽器內建朗讀，與本機開源模型預先錄好的語音。遊戲本身尚未更動，要不要替換由作者決定。
> English summary: the 24 story lines were rendered with a local open-source TTS (Kokoro-82M-v1.1-zh, Apache-2.0, CPU only) and checked by machine with Whisper. The game still uses browser speech; whether to switch is the author's call.

## 做法

| 項目 | 內容 |
|---|---|
| 模型 | Kokoro-82M-v1.1-zh：權重與聲線為 Apache-2.0，只用 CPU，不連網、不呼叫任何付費服務 |
| 聲線 | 沐炎用女聲 zf_017（語速 1.05）；灰翁用男聲 zm_009（語速 0.9）；無燈之主用男聲 zm_045（語速 0.8），合成後再把音高降到 0.82 倍 |
| 機器驗收 | 用 faster-whisper small 把每句語音轉回文字，原句與轉寫都轉成不帶聲調的拼音，再算編輯距離。這樣繁體、簡體或同音字的差異不會被算成錯 |
| 重跑 | `python scripts/voice_test.py --engine-dir <含 tts_kokoro.py 的資料夾> --out incoming/voice`。產出的語音檔不放進 repo |

## 結果（2026-11-16）

| 項目 | 數字 |
|---|---|
| 句數 | 24 |
| 語音總長 | 118.9 秒 |
| 模型載入 | 21.5 秒 |
| 24 句合成時間 | 合計 29.4 秒 |
| 音節錯誤率（整體） | 2.17%（錯誤音節數 ÷ 原句總音節數） |
| 沐炎 | 1.39% |
| 灰翁 | 1.61% |
| 無燈之主（有降音高） | 6.25% |
| 檔案大小 | 原始 WAV 共 5.7 MB；轉成 Opus 32 kbps 共 419 KB |

錯誤集中在三類：
- 句首的刪節號「……」被唸成一個音，例如「先點亮南邊的星之塔」前面多了一個音。
- 降過音高的無燈之主，「餘燼」被聽成另一組音。
- 「按 3」「按 4」的阿拉伯數字和前後文黏在一起。

## 試聽

每位說話者一句：
- [灰翁：沐炎，醒醒。墓園的四座燈塔，全熄了。](voice/intro_0_elder.ogg)
- [沐炎：天上的火掉下來了……燈塔以前是用來接住它們的？](voice/t3_1_mu.ogg)
- [無燈之主：我花了三百年才把它們吹熄。小小的火，你憑什麼？](voice/t4_2_lord.ogg)

## 兩種做法的差異

| 項目 | 瀏覽器內建朗讀（目前） | 本機模型預錄 |
|---|---|---|
| 聲音 | 依玩家的作業系統與瀏覽器而定，每台電腦不同 | 每台電腦都一樣 |
| 角色區分 | 同一個聲音，只調音高與語速 | 三個不同的聲線 |
| 下載量 | 0 | 約 419 KB（Opus） |
| 改台詞 | 改文字就生效 | 要重跑腳本重新產生語音檔 |
| 離線 | 部分瀏覽器的中文聲音要連網 | 語音檔載入後就可離線播放 |
| 授權 | 依瀏覽器與作業系統 | Apache-2.0（權重與聲線） |
