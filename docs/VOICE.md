# 語音實測 · Voice Test (P3d)

> 故事模式 24 句對白，比較兩種配音來源：瀏覽器內建朗讀，與本機開源模型預先錄好的語音。2026-11-16 作者決定改用預錄語音，遊戲已換上（見文末「採用」）。
> English summary: the 24 story lines were rendered with a local open-source TTS (Kokoro-82M-v1.1-zh, Apache-2.0, CPU only) and checked by machine with Whisper. Since 2026-11-16 the game plays these recordings and falls back to browser speech only when a file cannot play.

## 做法

| 項目 | 內容 |
|---|---|
| 模型 | Kokoro-82M-v1.1-zh：權重與聲線為 Apache-2.0，只用 CPU，不連網、不呼叫任何付費服務 |
| 聲線 | 沐炎用女聲 zf_017（語速 1.05）；灰翁用男聲 zm_009（語速 0.9）；無燈之主用男聲 zm_045（語速 0.8），合成後再把音高降到 0.82 倍 |
| 機器驗收 | 用 faster-whisper small 把每句語音轉回文字，原句與轉寫都轉成不帶聲調的拼音，再算編輯距離。這樣繁體、簡體或同音字的差異不會被算成錯 |
| 重跑 | `python scripts/voice_test.py --engine-dir <含 tts_kokoro.py 的資料夾> --out incoming/voice`。產出的語音檔不放進 repo |

## 結果（2026-11-16）

| 項目 | 數字 |
|---|---|
| 句數 | 24 |
| 語音總長 | 118.9 秒 |
| 模型載入 | 21.5 秒 |
| 24 句合成時間 | 合計 29.4 秒 |
| 音節錯誤率（整體） | 2.17%（錯誤音節數 ÷ 原句總音節數） |
| 沐炎 | 1.39% |
| 灰翁 | 1.61% |
| 無燈之主（有降音高） | 6.25% |
| 檔案大小 | 原始 WAV 共 5.7 MB；轉成 Opus 32 kbps 共 419 KB |

錯誤集中在三類：
- 句首的刪節號「……」被唸成一個音，例如「先點亮南邊的星之塔」前面多了一個音。
- 降過音高的無燈之主，「餘燼」被聽成另一組音。
- 「按 3」「按 4」的阿拉伯數字和前後文黏在一起。

## 試聽

每位說話者一句：
- [灰翁：沐炎，醒醒。墓園的四座燈塔，全熄了。](voice/intro_0_elder.ogg)
- [沐炎：天上的火掉下來了……燈塔以前是用來接住它們的？](voice/t3_1_mu.ogg)
- [無燈之主：我花了三百年才把它們吹熄。小小的火，你憑什麼？](voice/t4_2_lord.ogg)

## 兩種做法的差異

| 項目 | 瀏覽器內建朗讀（備案） | 本機模型預錄（採用） |
|---|---|---|
| 聲音 | 依玩家的作業系統與瀏覽器而定，每台電腦不同 | 每台電腦都一樣 |
| 角色區分 | 同一個聲音，只調音高與語速 | 三個不同的聲線 |
| 下載量 | 0 | 約 419 KB（Opus） |
| 改台詞 | 改文字就生效 | 要重跑腳本重新產生語音檔 |
| 離線 | 部分瀏覽器的中文聲音要連網 | 語音檔載入後就可離線播放 |
| 授權 | 依瀏覽器與作業系統 | Apache-2.0（權重與聲線） |

## 採用（2026-11-16）

| 項目 | 內容 |
|---|---|
| 檔案 | 24 個 Opus 檔放在 `content/demo/voice/`，檔名＝對白代號_第幾句_說話者，例如 `intro_0_elder.ogg` |
| 播放 | 每句對白出現時播放對應的檔；音量跟著設定裡的「語音」與「主音量」；點下一句、跳過或關閉對白會停止 |
| 備案 | 檔案放不出來時（例如不支援 Ogg Opus 的舊版 Safari）自動改用瀏覽器內建朗讀，字幕照常 |
| 載入 | 每句播放時才下載該句的檔，進遊戲不必先下載全部 |
| 測試 | 單元測試三項：24 句都有對應檔、對白播的是自己那句且關閉會停、放不出來時改用內建朗讀 |
| 改台詞時 | 用 `scripts/voice_test.py` 重新產生 WAV，再用 `ffmpeg -i 句.wav -c:a libopus -b:a 32k content/demo/voice/句.ogg` 轉成 Opus 32 kbps 單聲道覆蓋同名檔；單元測試會檢查句數與檔案是否對得上（不檢查內容是否為新台詞，改台詞後要重跑 Whisper 比對） |
